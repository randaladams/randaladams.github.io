# adamselite.com

Website for adamselite.com games and apps, published with GitHub Pages at https://adamselite.com.

| Path | What it is |
|---|---|
| `/app-ads.txt` | AdMob authorized-seller file (shared by every app that uses AdMob) |
| `/` | Games & apps list |
| `/apps/<app>/` | An app's page |
| `/apps/<app>/privacy/` | That app's privacy policy (use this URL in the Play Console) |

Apps: trench-run, horizon-run, stop-time, how-far-is-graceland, inner-circle, tuts-trumpets.

## Editing

All pages are generated by `tools/build_site.py`. To add an app or change a policy, edit the `APPS`
list in that file, add the icon to `assets/` (256 x 256 PNG), then run:

    python3 tools/build_site.py

and commit. Pushing to `main` publishes the site.

Notes:
- Apps live under `/apps/` so they never collide with older GitHub Pages sites in the individual app
  repositories (for example `/StopTime/privacy-policy.html`), which still work.
- `/trench-run/` redirects to `/apps/trench-run/`.
- `.nojekyll` turns off Jekyll processing; `CNAME` holds the custom domain.
