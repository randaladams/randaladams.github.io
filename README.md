# randaladams.github.io

Website for Adams Elite games, published with GitHub Pages.

| Path | What it is |
|---|---|
| `/app-ads.txt` | AdMob authorized-seller file (shared by every game that uses AdMob) |
| `/` | Games list |
| `/trench-run/` | Trench Run page |
| `/trench-run/privacy/` | Trench Run privacy policy (use this URL in the Play Console) |

To add a game: create a `game-name/` folder with an `index.html` and a `privacy/index.html`, and add a card to the home page.

The site is plain HTML (`.nojekyll` turns off Jekyll processing). Pushing to `main` publishes it.
